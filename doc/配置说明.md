# 配置说明

默认读取 `config/config.yaml`，可用 `CONFIG_FILE` 指定路径。配置不展开 `${VAR}`，修改后重启生效。[配置示例](../config/config.yaml.example)中的凭据均为占位值，真实配置不得提交仓库。

## 服务与鉴权

```yaml
server:
  address: ":8801"
  read_timeout_seconds: 10
  write_timeout_seconds: 10
auth:
  enabled: true
  token: "change-me"
```

- 服务默认值如上；超时单位为秒，省略或填 `0` 使用默认值，负数拒绝启动。
- 单次出站请求超时固定为 10 秒；所有通知处理共用写超时 90% 的请求预算，默认 9 秒，余下时间用于返回响应。预算包含请求体读取、渲染与拆分发送，读取还受读超时限制。到期取消出站请求并停止后续发送，返回 HTTP 504、code 50401；需要更长的批量处理时间时调整写超时。
- 鉴权默认开启，只有 `enabled: false` 才关闭。开启时 Token 不得为空或全为空白，否则无法启动。旧配置若省略开关且没有有效 Token，升级前需补齐。
- 全局 Token 可访问全部启用的 channel，没有 channel 级权限隔离。

## channel

本地模式至少配置一个 channel；名称以小写字母或数字开头，后续允许小写字母、数字、`-`、`_`。

下面的 Generic 示例需合并到现有 `channels`，替换 webhook 后使用：

```yaml
channels:
  ops-test:
    enabled: true
    platform: feishu
    webhook: "https://open.feishu.cn/open-apis/bot/v2/hook/example"
    template: generic_feishu
    at: []
```

| 字段 | 规则 |
|---|---|
| `enabled` | 可选，默认启用 |
| `platform` | 必填，`dingtalk` 或 `feishu` |
| `webhook` | 必填，包括禁用的 channel |
| `secret` | 钉钉、飞书均在非空时加签，为空或未配置时不加签 |
| `template` | 可选，不含 `.tmpl` 后缀，默认 `<source>_<platform>` |
| `at` | 默认接收人；钉钉使用手机号，飞书使用用户 ID |

飞书机器人开启签名校验时，须配置相同的 `secret`；网关在请求体中加入秒级 `timestamp` 和 `sign`。未配置时不发送这两个字段。平台拒绝签名时返回发送失败，不降级为无签名重发；部署环境应保持系统时间准确。

网关已支持飞书签名配置；当前 ops-agent-api / ops-agent-web 的渠道校验和表单仍限制飞书密钥，需联动调整后才能通过平台管理该字段。

## 渠道来源

同一个 YAML 文件允许保留本地 `channels` 和平台连接配置，通过 `channel_source.mode` 选择。省略模式默认 `file`，现有本地配置无需增加字段；修改模式、连接地址或 Token 后重启生效。

```yaml
channel_source:
  mode: platform
  platform:
    url: https://ops.example.com/api/v1/internal/notification-channels
    token: "replace-with-platform-read-token"
    recovery_file: /var/lib/ops-notify-gateway/channels.snapshot.yaml
    sync_interval_seconds: 30
    timeout_seconds: 5
```

| 配置 | 规则 |
|---|---|
| `mode` | `file` 或 `platform`，只读取和校验选中来源；YAML 本身须合法 |
| `platform.url` | 完整读取接口，不拼接路径；默认要求 HTTPS，仅主机名精确匹配 `localhost`、`127.0.0.1`、`::1` 时允许 HTTP（主机名不区分大小写，端口可自定义）；禁止 URL 内嵌凭据、查询参数或片段 |
| `platform.token` | 独立读取凭据，使用 Bearer；不得与 `auth.token` 相同 |
| `platform.recovery_file` | YAML 恢复文件路径，平台模式必填；建议使用专用私有目录，容器挂载持久卷 |
| `platform.sync_interval_seconds` | 省略或 `0` 默认 30，允许 1～86400 秒 |
| `platform.timeout_seconds` | 省略或 `0` 默认 5，允许 1～300 秒；独立于发送超时 |

本机联调可配置 `http://127.0.0.1:8080/api/v1/internal/notification-channels`，将 `8080` 替换为平台实际端口；IPv6 使用 `http://[::1]:8080/api/v1/internal/notification-channels`。HTTP 白名单固定在代码中，不使用域名后缀匹配，不扩展到其他回环 IP、局域网 IP 或 `host.docker.internal`。容器中的回环地址指向容器自身；其他地址继续使用 HTTPS。此例外仅适用于平台读取接口，不放宽机器人 Webhook 校验，拉取仍禁止重定向。

平台模式无需恢复文件加密密钥。`recovery_file` 保存可读的 YAML，包含 Webhook 和签名密钥明文，仅供网关自动维护；渠道变更在平台页面进行。相对路径以进程工作目录为准，目录须可写，恢复文件不得提交 Git。

两套渠道不合并，平台模式忽略本地 `channels`，故障时不会回退到它。两种模式均由 Jenkins、Alertmanager 等直接调用网关；平台模式必须开启 `auth.enabled`，入站 Token 仍由 `auth.token` 指定。

启动先拉取平台完整快照，校验后更新内存，再以 YAML 落盘。定时同步串行执行，合法空快照会清空渠道。同步失败保留最近成功配置；启动失败可加载恢复文件。无有效配置时 `/ping` 仍可用，但 `/ready` 和通知返回 HTTP 503。有效空快照也视为就绪。

恢复文件保存来源 URL、格式版本和同步时间，加载时严格校验格式、来源和所有渠道；文件上限 32 MiB，仅允许单个 YAML 文档，以权限 `0600` 的临时文件原子替换；创建目录使用 `0700`，既有目录权限由部署方管理。各实例使用自己的文件。文件损坏或来源不匹配时拒绝加载。落盘失败不回退当前内存，但重启可能恢复旧文件；同步及持久化状态见 `/ready`。断连时不按配置年龄自动停发。

旧加密 `.enc` 文件不自动转换或读取，也不会自动删除。升级时将 `recovery_file` 改为新的 `.yaml` 路径，并在平台可访问时启动以生成新快照；旧恢复密钥环境变量不再使用。

平台渠道使用来源对应的默认模板，要求明确的启用状态；仅接受钉钉官方机器人 HTTPS 地址或飞书官方机器人 HTTPS 地址，禁止重定向；钉钉和飞书均支持可选签名 secret。钉钉接收人为 5～20 位数字，飞书接收人为 1～128 位字母、数字、下划线或连字符，每次最多 100 个；发送时同样校验请求覆盖后的接收人。

平台接口返回统一响应 `code=200`、`data.version=1`、必填的 `data.channels` 数组；每项包含 `code/platform/webhook/secret/at/enabled`。最多 10000 个渠道，完整响应不超过 8 MiB。缺失/null 数组、重复 code、非法配置、截断及失败响应均拒绝整批更新，保留旧快照。

## 模板与接收人

模板位于工作目录下的 `templates/`，不随 `CONFIG_FILE` 改变。默认模板名由来源 `jenkins/alertmanager/generic` 和平台 `dingtalk/feishu` 组成，如 `jenkins_feishu.tmpl`。

显式指定模板后，该 channel 的所有来源均使用它；跨来源共用时应省略模板或确保字段匹配。模板每次发送时读取，文件缺失或渲染失败会导致通知失败。

Jenkins 使用默认 `at`；Generic 的非空 `at` 覆盖默认值；Alertmanager 规则见[接入说明](Alertmanager接入说明.md)。

发送前校验最终接收人格式，两种来源均适用。出站请求不跟随 HTTP 重定向。

## 日志

记录请求方法、路径、状态码、耗时和发送失败摘要。平台同步、恢复文件加载和保存的状态或错误原因变化时记录日志；相同错误不逐轮重复记录，恢复正常时清除诊断并记录恢复。`/ready` 的 `sync_error`、`persistence_error` 提供安全摘要，可区分平台 HTTP 状态、超时、非法快照以及文件缺失、权限、磁盘写入失败等情况。不记录完整 webhook、secret、Token、Authorization、平台原始响应或恢复文件路径。
