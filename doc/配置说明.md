# 配置说明

配置文件默认读取 `config/config.yaml`，也可以通过 `CONFIG_FILE` 指定。

## server

```yaml
server:
  address: ":8801"
  read_timeout_seconds: 10
  write_timeout_seconds: 10
```

## auth

```yaml
auth:
  enabled: true
  token: "${OPS_NOTIFY_TOKEN}"
```

生产环境建议保持 `enabled=true`。

## channels

```yaml
channels:
  jenkins-test:
    platform: "feishu"
    webhook: "${FEISHU_JENKINS_TEST_WEBHOOK}"
    secret: "${FEISHU_JENKINS_TEST_SECRET}"
    template: "jenkins_feishu"
    at: []
```

字段说明：

| 字段 | 说明 |
|---|---|
| `platform` | 通知平台，当前支持 `dingtalk`、`feishu` |
| `webhook` | 机器人 webhook，必须通过环境变量注入 |
| `secret` | 加签 secret，可选；钉钉启用加签时必填 |
| `template` | 模板名，不含 `.tmpl` 后缀 |
| `at` | 默认 @ 人列表 |

禁止提交真实 webhook、secret、token。

飞书 `secret` 字段已预留；第一版发送器暂不把签名写入请求体。
