# 接口文档

## 通用响应

成功：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

失败：

```json
{
  "code": 40001,
  "message": "channel is required",
  "data": null
}
```

## 鉴权

除 `/ping` 外，接口默认需要 Token 鉴权。

```text
Authorization: Bearer <token>
```

或：

```text
X-Webhook-Token: <token>
```

## 健康检查

```text
GET /ping
```

## Jenkins 通知

```text
POST /api/v1/notifications/jenkins
```

请求：

```json
{
  "channel": "jenkins-test",
  "status": "SUCCESS",
  "jobName": "cohort-build",
  "buildNumber": "123",
  "buildUrl": "http://jenkins/job/cohort-build/123/",
  "services": ["cohort-platform"],
  "branch": "release",
  "deployEnv": "test",
  "packageType": "image",
  "deploy": true,
  "deployType": "ssh",
  "triggerUser": "admin"
}
```

必填字段：`channel`、`status`、`jobName`、`buildNumber`、`buildUrl`。

`status` 允许：`SUCCESS`、`FAILURE`、`ABORTED`、`UNSTABLE`。

## Alertmanager 通知

```text
POST /api/v1/alerts/alertmanager?channel=alert-prod
```

Body 使用 Alertmanager webhook 原始结构。`channel` 必填。

## Generic 通知

```text
POST /api/v1/notifications/generic
```

请求：

```json
{
  "channel": "ops-test",
  "title": "任务执行完成",
  "status": "SUCCESS",
  "level": "info",
  "content": "备份任务执行完成",
  "url": "https://example.com/tasks/1"
}
```

必填字段：`channel`、`title`、`content`。
